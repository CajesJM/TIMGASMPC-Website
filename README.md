# TIMGAS MPC Website

The TIMGAS MPC Website is the official digital platform for the Tinabangay sa Igsoong Mag-uuma Gasa ni San Isidro Multi-Purpose Cooperative in Poblacion, Trinidad, Bohol. It presents the cooperative's identity, history, mission, vision, core values, objectives, social goals, public updates, certifications, and contact information in a responsive single-page website.

The platform gives prospective and existing members two ways to submit official membership and loan applications: they may complete a guided online form or download the original application document for manual completion. Online submissions include validation, reCAPTCHA protection, structured application previews, and secure storage in Firebase for manager review.

An access-controlled manager portal supports the cooperative's administrative workflow. Authorized managers can:

- Review, update, print, download, and remove membership and loan applications.
- Track application statuses and manager notes.
- Publish and manage announcements, news, achievements, and certifications shown on the public website.
- Upload and replace post images while keeping Firebase Storage records synchronized.
- Maintain their administrator profile, avatar, and account password.
- View dashboard summaries and application-processing information.

The website is built with React, TypeScript, Vite, and CSS Modules. Firebase provides authentication, Firestore data storage, file storage, server-side application processing, and administrative access control. The interface is designed to work across desktop, tablet, and mobile devices while preserving the appearance of TIMGAS MPC's official application documents.
